# 📘 Computer Components – MCQs for Exam Preparation

---

## 🖥️ Basic Concepts

**1. A computer consists of two main components:**  
A) Input and Output  
B) Hardware and Software  
C) CPU and RAM  
D) OS and Applications  
**Answer: B**

**2. Hardware refers to:**  
A) Programs and instructions  
B) Physical parts you can see and touch  
C) Internet services  
D) Applications only  
**Answer: B**

**3. Software is:**  
A) Physical equipment  
B) Storage device  
C) Programs that tell hardware what to do  
D) Networking device  
**Answer: C**

---

## 🧠 Types of Software

**4. Software that controls and manages hardware is called:**  
A) Application Software  
B) Utility Software  
C) System Software  
D) Customized Software  
**Answer: C**

**5. MS Word and Excel are examples of:**  
A) System Software  
B) Application Software  
C) Utility Software  
D) Firmware  
**Answer: B**

**6. Antivirus programs belong to:**  
A) Application Software  
B) Utility Software  
C) System Software  
D) Language Translators  
**Answer: B**

**7. Device Drivers are part of:**  
A) Utility Software  
B) Application Software  
C) System Software  
D) Customized Software  
**Answer: C**

---

## ⚙️ System Software

**8. System software provides:**  
A) Games only  
B) A platform for other software  
C) Internet connection  
D) Printing services only  
**Answer: B**

**9. Firmware is:**  
A) Application software  
B) Embedded software controlling hardware  
C) Antivirus software  
D) Word processing software  
**Answer: B**

**10. Language translators convert:**  
A) Images into text  
B) Data into information  
C) Programming code into machine code  
D) Files into folders  
**Answer: C**

**11. Which of the following is NOT a language translator?**  
A) Compiler  
B) Interpreter  
C) Assembler  
D) Printer Driver  
**Answer: D**

## 🖥️ Operating System (OS)

**12. The Operating System mainly:**  
A) Creates documents  
B) Manages hardware and software resources  
C) Scans for viruses  
D) Compresses files  
**Answer: B**

**13. Memory management is a function of the:**  
A) Application software  
B) Utility software  
C) Operating System  
D) Compiler  
**Answer: C**

**14. File management is performed by the:**  
A) OS  
B) Antivirus  
C) Browser  
D) AutoCAD

**15. CLI and GUI are types of:**  
A) Programming languages  
B) User interfaces  
C) Storage devices  
D) Utility tools  
**Answer: B**
