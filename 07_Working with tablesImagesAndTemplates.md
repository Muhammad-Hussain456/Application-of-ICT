# 📊 Working with Tables, Images, and Templates

---

# 📋 PART 1: TABLES

## Introduction to Tables

Tables organize information into rows and columns, making data easier to read, compare, and analyze. Essential for reports, schedules, pricing lists, and structured data.

---

## 🏗️ CREATING TABLES

### Microsoft Word

| Method | Steps |
|--------|-------|
| **Grid** | Insert → Table → Highlight cells (max 10×8) |
| **Insert Dialog** | Insert → Table → Insert Table → Set rows/columns |
| **Draw Table** | Insert → Table → Draw Table → Pencil tool |
| **Quick Tables** | Insert → Table → Quick Tables → Built-in templates |
| **Convert Text** | Select text → Insert → Table → Convert Text to Table |

**Shortcut:** `Alt+N`, `T` (then arrow keys)

### Google Docs

| Method | Steps |
|--------|-------|
| **Grid** | Insert → Table → Highlight cells |
| **Custom** | Insert → Table → Specify rows/columns |
| **Copy/Paste** | Paste from Sheets or Word |

**Shortcut:** Not available natively

---

## ✏️ TABLE FORMATTING

### 1. Selecting Elements

| Selection | Word | Google Docs |
|-----------|------|-------------|
| Cell | Click left edge | Click once |
| Row | Click left margin | Right-click → Select row |
| Column | Click top border | Right-click → Select column |
| Table | Click move handle | Right-click → Select table |

### 2. Adding/Removing

**Insert:**
- **Row Above:** Right-click → Insert → Insert Rows Above
- **Row Below:** Right-click → Insert → Insert Rows Below  
- **Column Left:** Right-click → Insert → Insert Columns to the Left
- **Column Right:** Right-click → Insert → Insert Columns to the Right

**Delete:**
- Right-click → Delete Cells/Columns/Rows/Table

**Shortcuts (Word):**
- `Tab` at end of last row → New row
- `Backspace` in empty cell → Delete options

### 3. Sizing

**Column Width:**
- Drag column border
- Double-click border → AutoFit to content
- **Word:** Layout → AutoFit → AutoFit Window/Contents/Fixed

**Row Height:**
- Drag row border
- **Word:** Layout → Height (exact value)
- **Docs:** Right-click row → Distribute rows

### 4. Alignment

**Text Alignment:**
| Alignment | Word | Google Docs |
|-----------|------|-------------|
| Horizontal | Layout → Align (Left/Center/Right) | Format → Align |
| Vertical | Layout → Align Top/Center/Bottom | Right-click → Cell vertical alignment |

**Table Position:**
- **Word:** Table Properties → Alignment (Left/Center/Right)
- **Docs:** Select table → Format → Align & indent

---

## 🎨 TABLE DESIGN

### Borders and Shading

**Word (Table Design Tab):**
- Border styles, weight, color
- Border painter
- Shading (fill color)
- Borders dropdown (all, outside, inside, none)

**Google Docs:**
- Border color (1pt default)
- Border width (pt)
- Border dash (solid, dotted, dashed)
- Cell background color

### Table Styles

**Word:**
- Built-in table styles (100+)
- Style options:
  - Header row
  - Total row
  - Banded rows
  - Banded columns
  - First column
  - Last column

**Google Docs:**
- Limited preset styles
- Custom formatting recommended

---

## 🔧 ADVANCED TABLE OPERATIONS

### 1. Merge and Split

**Merge Cells:**
1. Select adjacent cells
2. Right-click → Merge Cells
3. **Word shortcut:** `Alt+A`, `M`

**Split Cells:**
1. Select cell(s)
2. Right-click → Split Cells
3. Specify rows/columns

**Split Table (Word):**
- Place cursor in row → `Ctrl+Shift+Enter`
- Table breaks into two tables

### 2. Calculations

**Word:**
- Layout → Formula
- Functions: SUM, AVERAGE, COUNT, MIN, MAX
- Cell references: A1, B2 (like Excel)

**Google Docs:**
- No native calculation
- Use Google Sheets and embed

### 3. Sorting

**Word:**
- Layout → Sort
- Sort by column, type (text/number/date)
- Ascending/descending

**Google Docs:**
- Table → Sort table
- Sort ascending/descending
- Advanced: Sort by multiple columns

### 4. Repeat Header Rows

**Purpose:** Header row appears on each page for long tables

**Word:**
1. Select header row(s)
2. Layout → Repeat Header Rows
3. Toggle on/off

**Google Docs:**
1. Right-click header row
2. Pin header row

---

## 📊 TABLE BEST PRACTICES

✅ **DO:**
- Use header rows with distinct formatting
- Align numbers right, text left
- Avoid merged cells when sorting needed
- Keep tables simple (5-7 columns max)
- Add alt text for accessibility
- Use banded rows for readability

❌ **DON'T:**
- Use tables for page layout
- Overuse borders (gridlines suffice)
- Create overly wide tables
- Forget responsive design (mobile view)
- Nest tables excessively

# 🖼️ PART 2: IMAGES

## Introduction to Images

Images enhance documents by visualizing concepts, providing evidence, and improving engagement. Effective image placement balances aesthetics with readability.

---

## 📥 INSERTING IMAGES

### Microsoft Word

| Source | Path | Notes |
|--------|------|-------|
| **This Device** | Insert → Pictures → This Device | Local files |
| **Stock Images** | Insert → Pictures → Stock Images | Royalty-free library |
| **Online Pictures** | Insert → Pictures → Online Pictures | Bing search |
| **Icons** | Insert → Icons | Vector graphics |
| **Screenshot** | Insert → Screenshot | Screen clipping |
| **SmartArt** | Insert → SmartArt | Diagrams, processes |

### Google Docs

| Source | Path | Notes |
|--------|------|-------|
| **Upload** | Insert → Image → Upload from computer | Local files |
| **Drive** | Insert → Image → Drive | Google Drive |
| **Photos** | Insert → Image → Photos | Google Photos |
| **URL** | Insert → Image → By URL | Web images |
| **Camera** | Insert → Image → Camera | Webcam |
| **Search** | Insert → Image → Search the web | Stock photos |

**Shortcut:** `Alt+I`, `U` (Docs)

---

## 🔄 IMAGE FORMATTING

### 1. Text Wrapping

**Options Comparison:**

| Wrap Type | Word | Google Docs | Behavior |
|-----------|------|-------------|----------|
| **In Line** | In Line with Text | Inline | Image as text character |
| **Square** | Square | Wrap text | Text around rectangle |
| **Tight** | Tight | (similar) | Text around shape |
| **Through** | Through | - | Text fills gaps |
| **Top/Bottom** | Top and Bottom | Break text | Text above/below |
| **Behind** | Behind Text | Behind text | Watermark effect |
| **Front** | In Front of Text | - | Overlay |

**Shortcut (Word):** Select image → Format tab → Wrap Text

### 2. Positioning

**Absolute Positioning:**
- Fixed position on page
- Independent of text flow
- Measured from margin/page/paragraph

**Relative Positioning:**
- Moves with paragraph
- Anchored to text

**Alignment:**
- Left/Right/Center/Middle
- Distribute horizontally/vertically

### 3. Sizing

**Methods:**
- Drag corner handles (maintain aspect ratio)
- Drag side handles (distort)
- Format tab → Size (exact dimensions)

**Crop:**
1. Select image
2. Format → Crop
3. Drag crop handles
4. Press Enter

**Crop to Shape (Word):**
- Format → Crop → Crop to Shape
- Choose from shapes gallery

---

---

## 🖼️ ADVANCED IMAGE TECHNIQUES

### 1. Grouping

**Word:**
1. Select multiple images (Ctrl+Click)
2. Format → Group → Group
3. Or right-click → Group → Group

**Google Docs:**
- Limited grouping
- Use Drawing tool for complex layouts

### 2. Captions

**Word:**
1. Right-click image
2. Insert Caption
3. Label options (Figure, Table, Equation)
4. Numbering format

**Google Docs:**
- Manual text below image
- Use table for alignment
- No automatic numbering

### 3. Alt Text (Accessibility)

**Purpose:** Screen reader descriptions, SEO

**Word:**
1. Right-click → Edit Alt Text
2. Describe image purpose
3. Mark as decorative if purely visual

**Google Docs:**
1. Right-click → Alt Text
2. Title and description fields

### 4. Compression

**Word:**
1. Select image
2. Format → Compress Pictures
3. Options:
   - Apply to selected/all
   - Delete cropped areas
   - Resolution (PPI)

**Google Docs:**
- Automatic compression
- No manual control

---

## 📐 LAYOUT BEST PRACTICES

### Image Placement Guidelines

```
PRINT DOCUMENTS:
- Place images near relevant text
- Avoid splitting images across pages
- Maintain consistent margins
- Use 300 DPI minimum for print

DIGITAL DOCUMENTS:
- Optimize file size (72-150 DPI)
- Use responsive sizing
- Consider mobile viewing
- SVG/Vector for logos
```

### Common Layout Patterns

**Single Column:**
```
┌─────────────────┐
│      Text       │
├─────────────────┤
│      IMAGE      │
├─────────────────┤

└─────────────────┘

**Text Wrap:**

│ Text            │
└─────────────────┘
```

**Side-by-Side:**
```
┌─────────────────┐

│ │ 1 │  │ 2 │   │
│ └───┘  └───┘   │
│   Captions      │
└─────────────────┘
```

# 📁 PART 3: TEMPLATES

## Introduction to Templates

Templates are pre-formatted documents that serve as starting points, ensuring consistency and saving time. Essential for standardization across organizations.

---

## 🎯 TEMPLATE TYPES

### Common Templates

| Category | Examples |
|----------|----------|
| **Business** | Letters, Invoices, Reports, Proposals |
| **Academic** | Papers, Resumes, Cover Letters, Presentations |
| **Administrative** | Forms, Meeting Minutes, Agendas |
| **Marketing** | Brochures, Flyers, Newsletters |
| **Personal** | Calendars, Budgets, Invitations |

---

## 📌 CREATING TEMPLATES

### Microsoft Word

**Method 1: Save as Template**
1. Create document with formatting, styles, placeholders
2. File → Save As
3. Choose file type: **Word Template (*.dotx)**
4. Default location: Custom Office Templates

**Method 2: Create from Existing**
1. Open existing document
2. File → Save As → Word Template
3. Modify as needed

**Template Elements:**
- Styles (consistent formatting)
- Building blocks (reusable content)
- Content controls (form fields)
- Headers/footers
- Company logo
- Placeholder text

### Google Docs

**Method 1: Create Template**
1. Create document
2. Rename to "Template - [Name]"
3. Store in "Templates" folder
4. Make copies for each use

**Method 2: Template Gallery**
1. Open Google Drive
2. New → Google Docs → From a template
3. Submit template for organization

**Google Workspace:**
- Organization-wide templates
- Template Gallery admin settings

---

## 🔧 WORKING WITH TEMPLATES

### Using Templates

**Word:**
1. File → New
2. Search online templates
3. Personal: File → New → Personal
4. Pin templates for quick access

**Google Docs:**
1. docs.google.com
2. Template Gallery
3. Organization templates
4. Make a copy to edit

### Modifying Templates

**Word:**
1. File → Open → Browse
2. Navigate to Custom Office Templates
3. Open .dotx file
4. Edit and save

**Google Docs:**
1. Open template file
2. Edit content
3. File → Save as Google Docs
4. Or overwrite template

---

## 🎨 DESIGNING EFFECTIVE TEMPLATES

### Essential Components

```
┌─────────────────────────────────┐
│          HEADER                 │
│  Logo + Company Name           │
├─────────────────────────────────┤
│                                  │
│  [PLACEHOLDER: TITLE]          │
│                                  │
│  [CONTENT AREA]                │
│  • Body text style             │
│  • Consistent spacing          │
│  • Bullet points               │
│                                  │
├─────────────────────────────────┤
│          FOOTER                │
│  © Year | Page X of Y         │
└─────────────────────────────────┘
```

### Placeholder Text

**Word:**
- Lorem Ipsum generator
- Content controls (Developer tab)
- Rich text/plain text controls
- Date picker
- Dropdown lists

**Google Docs:**
- Manual placeholder text
- Smart chips (mentions, dates)
- Building blocks

---

## 📋 TEMPLATE BEST PRACTICES

### ✅ DO:
- Use styles, not manual formatting
- Include clear instructions (hidden or visible)
- Test templates before distribution
- Version control templates
- Protect template files (read-only)
- Use consistent naming conventions
- Train users on template usage

### ❌ DON'T:
- Hard-code content (use placeholders)
- Overcomplicate design
- Forget mobile formatting
- Store templates locally only
- Use inconsistent branding

---

### Version Control

**Naming Convention:**
- `TemplateName_v1.0.dotx`
- `TemplateName_2025.dotx`
- `Department_TemplateName.dotx`

**Update Process:**
1. Propose changes
2. Review and approve
3. Update master template
4. Communicate changes
5. Archive old version

## 💡 SUMMARY

**Tables** organize data effectively when:
- Using clear headers and consistent formatting
- Aligning content appropriately
- Repeating headers for multi-page tables
- Avoiding unnecessary merging

**Images** enhance communication when:
- Placed near relevant text
- Properly wrapped and sized
- Provided with alt text
- Optimized for medium (print/digital)

**Templates** ensure consistency when:
- Built on styles, not manual formatting
- Include clear placeholders
- Properly protected and versioned
- Accessible to all users

---

> "Good document design is invisible. Tables organize without clutter, images illustrate without distraction, and templates guide without restricting."
