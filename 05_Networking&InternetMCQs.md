# 📘 Networking & Internet – MCQs for Exam Preparation

---

## 🌐 Concept of Computer Network

**1. A computer network is defined as:**  
A) A single powerful computer  
B) A group of interconnected devices that exchange data  
C) A storage system  
D) An operating system  
**Answer: B**

**2. A computer network enables:**  
A) Only printing  
B) File sharing and internet access  
C) CPU processing  
D) Hardware installation  
**Answer: B**

**3. Networks can be:**  
A) Wired only  
B) Wireless only  
C) Both wired and wireless  
D) Satellite only  
**Answer: C**

**4. Routers and switches are examples of:**  
A) Input devices  
B) Storage devices  
C) Network devices  
D) Output devices  
**Answer: C**

---

## 🔗 Types of Network Connections

**5. A Point-to-Point (P2P) connection is:**  
A) Shared by many devices  
B) A direct link between two devices  
C) Wireless only  
D) Satellite-based  
**Answer: B**

**6. A key characteristic of Point-to-Point connection is:**  
A) Multiple senders and receivers  
B) Shared communication channel  
C) One sender and one receiver  
D) Unlimited devices  
**Answer: C**

**7. A Multipoint connection:**  
A) Connects only two devices  
B) Uses separate cables for each device  
C) Shares a single communication channel among multiple devices  
D) Is always wired  
**Answer: C**

**8. A Wi-Fi network shared by many devices is an example of:**  
A) Point-to-Point  
B) Multipoint  
C) Ring topology  
D) Mesh topology  
**Answer: B**

**9. In Multipoint connections, communication can be:**  
A) Only synchronous  
B) Only asynchronous  
C) Both synchronous and asynchronous  
D) None of these  
**Answer: C**

**10. A dedicated private link between two offices using a telephone line is:**  
A) Multipoint  
B) Mesh  
C) Point-to-Point  
D) Bus  
**Answer: C**

## 🧩 Network Topologies

**11. Network topology refers to:**  
A) Speed of internet  
B) Physical or logical layout of devices  
C) Type of operating system  
D) Data storage method  
**Answer: B**

**12. In Bus topology, devices are connected to:**  
A) A central hub  
B) Every other device  
C) A single backbone cable  
D) A circular loop  
**Answer: C**

**13. An advantage of Bus topology is:**  
A) High reliability  
B) Easy to set up and low cost  
C) No cable needed  
D) High security  
**Answer: B**

**14. In Star topology, all devices connect to:**  
A) A backbone cable  
B) A central hub or switch  
C) Each other directly  
D) A satellite  
**Answer: B**

**15. A disadvantage of Star topology is:**  
A) Difficult management  
B) Limited cable length  
C) Hub failure affects the network  
D) Expensive cables only  
**Answer: C**

**16. In Ring topology, devices are connected:**  
A) In a straight line  
B) To a central hub  
C) In a circular loop  
D) Randomly  
**Answer: C**

**17. Which topology is highly reliable but expensive and complex?**  
A) Bus  
B) Star  
C) Mesh  
D) Ring  
**Answer: C**

**18. Tree topology is a combination of:**  
A) Ring and Mesh  
B) Star and Bus  
C) Bus and Mesh  
D) Star and Ring  
**Answer: B**

**19. Hybrid topology is:**  
A) Only star-based  
B) Only ring-based  
C) A combination of multiple topologies  
D) A wireless-only network  
**Answer: C**

**20. Network topology affects:**  
A) Only speed  
B) Performance, reliability, and cost  
C) File size  
D) Printer quality  
**Answer: B**

## 📡 Data Communication

**21. Data communication is:**  
A) File storage  
B) Exchange of data between devices  
C) CPU processing  
D) Device repair  
**Answer: B**

**22. The device that sends data is called:**  
A) Receiver  
B) Medium  
C) Sender  
D) Protocol  
**Answer: C**

**23. The rules governing data transmission are called:**  
A) Message  
B) Protocol  
C) Medium  
D) Channel  
**Answer: B**

**24. The path through which data travels is known as:**  
A) Protocol  
B) Sender  
C) Medium/Channel  
D) Receiver  
**Answer: C**

**25. The actual data being transmitted is called:**  
A) Protocol  
B) Message  
C) Channel  
D) Network  
**Answer: B**

## 📘 Mixed Concept Questions

**31. LAN using bus topology is an example of:**  
A) Point-to-Point  
B) Multipoint  
C) Ring  
D) Mesh  
**Answer: B**

**32. A single point of failure exists in:**  
A) Mesh topology  
B) Star topology (hub failure)  
C) Multipoint connection  
D) Fiber optic cable  
**Answer: B**

**33. Guided media includes:**  
A) Radio waves  
B) Microwave  
C) Twisted pair cable  
D) Satellite  
**Answer: C**

**34. The combination of connection type creates:**  
A) Protocol  
B) Network topology  
C) Transmission speed  
D) Hardware  
**Answer: B**

**35. Sender, Receiver, Message, Medium, and Protocol are elements of:**  
A) Network topology  
B) Data communication  
C) Operating system  
D) Utility software  
**Answer: B**
