📘 Introduction to ICT – MCQs

🖥️ What is a Computer?

1. A computer is best defined as:
A) A mechanical calculating device
B) An electronic device that processes data into information
C) A communication tool only
D) A storage machine only
✅ Answer: B

2. The set of instructions that a computer follows is called:
A) Data
B) Hardware
C) Program
D) Knowledge
✅ Answer: C

3. Which of the following is NOT a function of a computer?
A) Input
B) Processing
C) Guessing
D) Output
✅ Answer: C

4. Creating presentations and calculating marks are examples of:
A) Communication
B) Computing tasks
C) Knowledge
D) Procedures
✅ Answer: B


---

🔹 Data, Information, and Knowledge

5. Raw facts and figures are called:
A) Information
B) Knowledge
C) Data
D) Procedures
✅ Answer: C

6. “Average = 84” is an example of:
A) Data
B) Information
C) Knowledge
D) Hardware
✅ Answer: B

7. Understanding that a student needs improvement is:
A) Data
B) Information
C) Knowledge
D) Communication
✅ Answer: C

8. Correct flow of concepts is:
A) Information → Data → Knowledge
B) Knowledge → Data → Information
C) Data → Information → Knowledge
D) Data → Knowledge → Information
✅ Answer: C


---

⚙️ What is Computing?

9. Computing involves:
A) Only storing data
B) Only communication
C) Input, processing, storage, and output
D) Typing documents only
✅ Answer: C

10. In short, computing means:
A) Using machines to calculate
B) Using computers to work with information
C) Sending emails
D) Using hardware only
✅ Answer: B


---

📡 What is Communication?

11. Communication is the:
A) Storage of data
B) Processing of information
C) Exchange of information
D) Use of hardware
✅ Answer: C

12. Phone calls are an example of:
A) Digital communication
B) Non-verbal communication
C) Verbal communication
D) Written communication
✅ Answer: C

13. Emails and video calls fall under:
A) Verbal communication
B) Digital communication
C) Non-verbal communication
D) Manual communication
✅ Answer: B


---

🌐 What is ICT?

14. ICT stands for:
A) International Computer Technology
B) Information and Communication Technology
C) Internal Communication Tool
D) Integrated Computer Techniques
✅ Answer: B

15. ICT is the integration of:
A) Hardware and software
B) Data and knowledge
C) Computing and communication
D) People and procedures
✅ Answer: C


---

🌟 Importance of ICT

16. Sending emails quickly shows ICT:
A) Reduces storage
B) Improves communication
C) Increases hardware
D) Eliminates knowledge
✅ Answer: B

17. Online classes are an example of ICT in:
A) Business
B) Communication
C) Education
D) Hardware
✅ Answer: C

18. Online shopping and digital payments show ICT in:
A) Education
B) Business
C) Knowledge
D) Hardware
✅ Answer: B

19. Using spreadsheets for calculations increases:
A) Communication
B) Productivity
C) Hardware size
D) Manual work
✅ Answer: B

20. Social media connecting people globally shows ICT:
A) Connects the world
B) Stores data
C) Reduces productivity
D) Removes communication
✅ Answer: A
