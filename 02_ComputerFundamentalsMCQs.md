## ⚙️ Characteristics of a Computer

**1. The ability of a computer to process data very quickly is called:**  
A) Accuracy  
B) Speed  
C) Storage  
D) Diligence  
**Answer: B**

**2. Performing tasks without making mistakes refers to:**  
A) Speed  
B) Versatility  
C) Accuracy  
D) Connectivity  
**Answer: C**

**3. The capability of storing a large amount of data is known as:**  
A) Automation  
B) Storage  
C) Diligence  
D) Processing  
**Answer: B**

**4. The ability to perform different types of tasks is called:**  
A) Versatility  
B) Accuracy  
C) Connectivity  
D) Input  
**Answer: A**

**5. A computer never gets tired or bored. This characteristic is called:**  
A) Automation  
B) Speed  
C) Diligence  
D) Storage  
**Answer: C**

**6. When a computer works automatically after receiving instructions, it shows:**  
A) Connectivity  
B) Automation  
C) Versatility  
D) Accuracy  
**Answer: B**

**7. The ability of computers to connect with other devices is known as:**  
A) Storage  
B) Processing  
C) Connectivity  
D) Diligence  
**Answer: C**

## 🔹 Functions of a Computer (IPO Cycle)

**8. IPO stands for:**  
A) Input, Process, Output  
B) Input, Processing, Output  
C) Input, Processing, Storage, Output  
D) Information, Process, Output  
**Answer: C**

**9. Taking data from the user is called:**  
A) Output  
B) Processing  
C) Input  
D) Storage  
**Answer: C**

**10. Calculating total marks is an example of:**  
A) Input  
B) Processing  
C) Storage  
D) Output  
**Answer: B**

**11. Saving a file for future use is:**  
A) Output  
B) Processing  
C) Storage  
D) Input  
**Answer: C**

**12. Displaying results on the screen is:**  
A) Input  
B) Storage  
C) Processing  
D) Output  
**Answer: D**

**13. Correct IPO sequence is:**  
A) Input → Storage → Processing → Output  
B) Processing → Input → Output → Storage  
C) Input → Processing → Storage → Output  
D) Storage → Input → Processing → Output  
**Answer: C**

A) Special-purpose computer

**15. An ATM machine is classified as:**  
A) General-purpose  
B) Supercomputer

## 🧬 Computer Generations

**20. First generation computers used:**  
A) Transistors  
B) Microprocessors  
C) Vacuum Tubes  
D) Integrated Circuits  
**Answer: C**

**21. Second generation computers were based on:**  
A) Vacuum Tubes  
B) Transistors  
C) ICs  
D) AI  
**Answer: B**

**22. Integrated Circuits (ICs) were used in the:**  
A) First generation  
B) Second generation  
C) Third generation  
D) Fourth generation  
**Answer: C**

**23. Microprocessors are used in the:**  
A) Third generation  
B) Fourth generation

D) First generation  
**Answer: B**

**24. AI and Quantum Computing belong to the:**  
A) Fourth generation  
B) Third generation

A) First  
B) Second
