# 📘 Computer Parts / Components – MCQs for Exam Preparation

---

## 🖥️ Basic Concepts

**1. A computer has two main components:**  
A) Input and Output  
B) Hardware and Software  
C) CPU and GPU  
D) Storage and Networking  
**Answer: B**

**2. Hardware refers to:**  
A) Programs and applications  
B) Physical parts you can touch  
C) Internet services  
D) Operating systems only  
**Answer: B**

**3. Software is:**  
A) Physical device  
B) Storage medium  
C) Programs that tell hardware what to do  
D) Input device  
**Answer: C**

---

## ⌨️ Input Devices

**4. Which device is used to type letters and numbers?**  
A) Mouse  
B) Keyboard  
C) Scanner  
D) Stylus  
**Answer: B**

**5. A mouse is mainly used to:**  
A) Record sound  
B) Print documents  
C) Point and click  
D) Store data  
**Answer: C**

**6. A scanner is used to:**  
A) Display visuals  
B) Convert documents into digital form  
C) Play sound  
D) Connect networks  
**Answer: B**

**7. Which device records sound?**  
A) Speaker  
B) Microphone  
C) Monitor  
D) Projector  
**Answer: B**

**8. A stylus is used to:**  
A) Print labels  
B) Draw or write on a touchscreen  
C) Store data  
D) Connect to Wi-Fi  
**Answer: B**

**9. A trackball is used to:**  
A) Capture images  
B) Move the cursor using a ball  
C) Amplify sound  
D) Process data  
**Answer: B**

**10. A camera is an input device because it:**  
A) Displays visuals  
B) Captures images and video  
C) Stores data  
D) Prints documents  
**Answer: B**

B) Display visuals

**13. Speakers and headphones are examples of:**

B) Storage devices

A) Store files

## 🧠 Processing Devices

**16. The main processing unit of a computer is the:**  
A) GPU  
B) CPU  
C) SSD  
D) Router  
**Answer: B**

**17. The GPU is responsible for:**  
A) Storing data  
B) Handling graphics and visual tasks  
C) Connecting networks  
D) Recording sound  
**Answer: B**

**18. TPU is specially designed for:**  
A) Gaming  
B) AI/ML computations  
C) Printing  
D) Storage  
**Answer: B**

**19. A co-processor:**  
A) Replaces the CPU  
B) Assists the main CPU  
C) Connects networks  
D) Stores files  
**Answer: B**

**20. DSP stands for:**  
A) Digital Storage Processor  
B) Data System Processor  
C) Digital Signal Processor  
D) Direct System Processor  
**Answer: C**

## 💾 Storage Devices

**21. HDD is a:**  
A) Optical storage device  
B) Magnetic storage device  
C) Input device  
D) Network device  
**Answer: B**

**22. SSD is known for being:**  
A) Slow and noisy  
B) Fast and reliable flash storage  
C) Optical storage  
D) Network hardware  
**Answer: B**

**23. A USB drive is mainly used for:**  
A) Processing  
B) Portable data storage  
C) Printing  
D) Audio output  
**Answer: B**

**24. CD/DVD are examples of:**  
A) Flash storage  
B) Optical storage media  
C) Magnetic disks  
D) Processing devices  
**Answer: B**

**25. Cloud storage means:**  
A) Data stored on a floppy disk  
B) Online data storage service  
C) Physical USB storage  
D) Local hard drive storage  
**Answer: B**

**26. Which of the following is an old magnetic storage medium?**  
A) SSD  
B) Floppy Disk  
C) Memory Card

## 🌐 Networking Devices

**27. A router is used to:**  
A) Store data  
B) Connect multiple networks together  
C) Display visuals  
D) Record sound  
**Answer: B**

**28. A modem connects a network to:**  
A) Printer  
B) Monitor  
C) Internet (ISP)  
D) GPU  
**Answer: C**

**29. A switch connects:**  
A) Different countries  
B) Devices within a network  
C) Storage devices  
D) Output devices  
**Answer: B**

**30. An access point provides:**  
A) Wired connection only  
B) Wireless (Wi-Fi) access  
C) Storage  
D) Printing  
**Answer: B**

**31. A network adapter enables:**  
A) Printing  
B) Processing  
C) Network connectivity on a device  
D) Sound recording  
**Answer: C**

**32. A bridge is used to:**  
A) Store files  
B) Connect and manage network segments  
C) Print labels  
D) Process graphics  
**Answer: B**
